# Attribution

Machine-readable provenance for every asset ships alongside it — this page
just explains where to find it and how it's structured. It does not
reproduce individual attributions (14 books' worth); read the files.

## Per-book manifest

Every seeded book has `packages/content/packs/<locale>/books/<bookId>/attribution.json`,
written by `pnpm content:build` from the source bundle's provenance fields
(CONTRACTS §2a). Shape:

```jsonc
{
  "schemaVersion": 1,
  "bookId": "es-fabulas-samaniego",
  "text": {
    "author": "...", // original author of the source work
    "sourceEdition": "...", // edition + where it came from (e.g. Project Gutenberg)
    "sourceUrl": "...",
    "sourceJurisdiction": "...", // why the source is public domain / freely adaptable
    "adaptationEditor": "...", // who/what produced the Sotto abridgment
    "license": { "spdx": "CC-BY-SA-4.0", "attribution": "..." },
  },
  "glosses": { "editor": "...", "license": { "spdx": "...", "attribution": "..." } },
  "cover": { "generator": "...", "license": { "spdx": "...", "attribution": "..." } },
  "audio": { "engine": "...", "license": { "spdx": "...", "attribution": "..." } },
}
```

Four independently-licensed pieces per book: the abridged **text**, the
**glosses**/translations, the generated **cover** art, and the generated
**audio** narration. `pnpm content:validate` requires `text.license.spdx`
and `text.license.attribution` on every book (CONTRACTS §2b) and errors if
`attribution.json` is missing entirely.

## What's actually in every book tonight

Every one of the 14 seeded books, without exception:

- Is an **AI-drafted abridgment** (`adaptationEditor: "Sotto contributors (AI
first draft, unreviewed)"`, `reviewStatus: "draft"` in `book.json`) of a
  **public-domain** source text (author-death-based public domain, or
  equivalent). No modern commercial abridgment or translation was used as a
  source — see [verification.md](verification.md) criterion 27, marked
  **DEFERRED**: no book has a recorded _human_ language review yet.
- Text + glosses: **CC BY-SA 4.0**, attributed to "Sotto contributors" plus
  the original public-domain author.
- Cover: an original, deterministically-seeded flat-geometric SVG
  (`pnpm content:covers`), **CC BY-SA 4.0**.
- Audio (where present — see [supported-languages.md](supported-languages.md)
  for which books have narration): generated by **Kokoro-82M** (Apache-2.0
  _model_; the _generated audio_ itself is licensed CC BY-SA 4.0, per
  `attribution.json`'s `audio.license`).

## License split (repo-wide)

- **Code** (`apps/`, `packages/*/src`, tooling): [Apache-2.0](../LICENSE).
- **Content** (`packages/content/source`, `packages/content/packs` —
  abridged texts, glosses, generated covers, generated audio):
  [CC BY-SA 4.0](../packages/content/LICENSE-CONTENT). See
  `packages/content/README.md`.

## Third-party model/tooling attribution

Not content assets, but worth listing since their outputs ship in the repo:

- **Kokoro-82M** (TTS) — Apache-2.0 model, generates the narration audio.
- **Whisper** (STT, via whisper.cpp or faster-whisper/speaches) — used only
  at build time (`pnpm content:narrate`'s word-alignment step) and at
  runtime for the live voice tutor; no Whisper output ships as a static
  asset.
- **Qwen3.6-35B-A3B** (LLM) — runtime tutor model only, nothing shipped.

## Adding a new book

Fill in every provenance field in the source bundle (CONTRACTS §2a:
`author`, `sourceEdition`, `sourceUrl`, `sourceJurisdiction`,
`adaptationEditor`, `license`) — `pnpm content:build` derives
`attribution.json` from those automatically. See
[adding-a-language.md](adding-a-language.md).
