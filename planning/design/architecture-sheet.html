Sotto, as built.

A voice-first graded reader: two apps and three packages in one pnpm workspace, TypeScript strict, ESM, Node 26. Everything a reader does lives on the device; the server only serves packs and relays voice.

apps/clientExpo · iOS + web

Navigation
Expo Router, file-based. Three tabs (home, library, vocabulary); onboarding, book, reader, voice, review, profile and settings are stack screens with the tab bar hidden.
State
Zustand slices: preferences, library, progress, vocabulary, session, ui.One Persistence adapter: idb-keyval on web, expo-sqlite as key-value on native.
Persistence
Everything on-device, no accounts. Export and import is one JSON document, { format: 'sotto-export', version: 1 }.
Tools
The tutor's tools run here, validated with zod, against the store.get_current_passage · set_reading_position · save_vocabulary · remove_vocabulary · show_explanation · set_session_mode · mark_section_complete
Type
Fraunces 300 and 400 via @expo-google-fonts; Inter for UI; catalogs in src/i18n/*.json through useT().

apps/serverFastify · :8790

Routes
GET /health · GET /content/packs · GET /content/packs/:locale/* · POST /voice/session · POST /import · GET /import/:jobId/events · GET /import/:jobId/result · POST /import/:jobId/narrate/:chapterIndex
Voice
Creates a session and returns a WebSocket URL; relays audio in and JSON events out.src/voice: chunker, vad, stt, llm, prompt, markers, tts, wav, session, registry, tools.
Wire
Client audio: PCM16 mono 16 kHz frames as binary messages. Server: JSON mirroring the VoiceEvent union, so FakeVoiceProvider emits the same shape from fixtures.
Import
DRM-free EPUB, TXT or Markdown become a private pack on your own server, with per-chapter narration on request.
Security
src/security.ts; hardening branch in flight (security/hardening-2026-09-07).

pnpm content:narrate · CONTRACTS §2c
01bundle.json

Sentences with translations, written by an author or adapted from a public-domain text.

02content:build

Tokenizes every sentence; writes pack.json and per-chapter token JSON.

03Kokoro TTS

Local endpoint renders the chapter to audio, one voice per locale (ff_siwis, ef_dora, af_heart…).

04Transcribe

The generated audio is transcribed with word-level timestamps.

05Align

Timestamped words are aligned back onto the pack's pre-tokenized text.

06Write

An mp3 plus per-token startMs and endMs in the chapter JSON, with caching and fallback rules.

07Speech fill

In the reader each word turns from quiet to ink as the narrator reaches it, 60ms stagger.

Decisions held

No accounts, no analytics. Everything runs in the browser; a book you have opened keeps working offline. WebRTC deferred: PCM over WebSocket for v1. Tools execute client-side: the server relays and never fabricates a successful result.

Stale on purpose

docs/contracts.md is an early verbatim copy; planning/CONTRACTS.md is the one that stayed current. The client's src/i18n/ is the only live catalog location.

Honest caveats

Books are machine-adapted drafts and their levels are estimates (docs/content-qa.md). The in-browser WebGPU tutor is still being finished (docs/browser-tutor.md). What is verified is tracked in docs/verification.md.
