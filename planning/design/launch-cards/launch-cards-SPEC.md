# Sotto launch cards, spec (2026-09-06, for the 2026-09-07 thread)

Fit read: job is being persuaded in ten seconds inside an X timeline, on a phone, with the real product as the only asset; lives one day; so: light Sotto paper posters, one screenshot per card, one line each.

Register: **poster** (one graphic object dominates, minimal copy). Last three ledger rows are directions sheet / guided sequence / scrollytelling stage, so no repeat.
Anchor: **Medium cream broadsheet** discipline (aggressively monochrome, serif never bold, left-aligned two-column hero 55/45) set on Sotto's own paper tokens instead of Medium's cream; the one filled colour is Sotto's coral, not Medium's #191919. Previous anchor (three cover anchors) differs.
Flood: #F4ECDF canvas, #FBF6EC surface. Emphasis hue #E4572E, ONE appearance per card (the pointer dot, or the ribbon already in the screenshot).
Device: **the staged page**: the real phone screenshot stands as a paper object with the 6px peach cutout, and one coral dot with a hairline tether points at the single thing the card is about. Content-carrying: the screenshot is the proof.
Type cast: Fraunces 300 display (Iowan Old Style / Georgia stand-in), 96px on a 1600x900 card, tracking -0.02em, lh 1.0; Inter/system sans 400 for the one caption line at 28px; mono 16px 0.08em uppercase for the eyebrow and footer.
Grid: card 1600x900, padding 96; text column 56%, object column 44%; screenshot shown at native 375px wide, never upscaled; baseline of the display sits on the card's horizontal centre.
Ban list: no gradients, no blurred shadows, no device bezel, no rounded pill anything, no second colour beyond coral, no bold serif.
Definition of done: cleo_verify 0 FAIL; five PNGs at 1600x900 read as images; text on paper >= 4.5:1; nothing overlaps at card size.
