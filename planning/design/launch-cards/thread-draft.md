# Sotto launch thread, draft for 2026-09-07 (Noel edits before posting)

Image per tweet: png/sotto-launch-N.png (1600x900).

1 (sotto-launch-1.png)
I built a graded reader you can talk to. Sotto: read a short book rewritten to your level, tap any word, hear it read, then say what you think out loud to a tutor that read the same page. Free, open source, no account. readsotto.app

2 (sotto-launch-2.png)
Same story, your level. Daudet's original next to Sotto's A2 rewrite of the same sentence. Pick a language and a level, A0 to C1, and the book is rewritten to fit.

3 (sotto-launch-3.png)
Tap any word. You get the meaning, the sound, and the sentence it lives in. Save it and the mark stays on the page, so a chapter ends up showing your own marks.

4 (sotto-launch-4.png)
Then talk about it. A voice tutor that already read the page asks you about it and listens. You answer in the language, out loud.

5 (sotto-launch-5.png)
Where the tutor runs is a footnote, not a tier. On this device, with your own OpenAI key, or self-hosted with docker compose up: all free. A hosted plan exists for people who want nothing to set up. Code is Apache-2.0, stories CC BY-SA, no analytics.
