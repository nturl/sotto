The card and the tile.

Four bets for the link preview and the app icon, each carrying the install book with it. The axis is what a stranger meets first: the object, the mechanism, the voice, or the name. Three from this desk and one, rebuilt, from the cross-family pass. Same paper, same faces, four different promises.

Today, for the record

The card carries six things and the drawn book turns to grey bars at 300px. The install section promises a teal book; the tile that actually lands is the line drawing on paper. Every direction below fixes both: one thing on the card, and the install section shows the real tile.

A

The Cover

This direction says: Sotto is a book you own. The teal cover from the install section becomes the one object that is the card, the tile, and the splash.

Commits to

  • One object everywhere: card, tile, install section, splash, share sheet.

Trades away

The Promise
