# Common rules for every run 7 lane (read before your card)

- Repo `~/Claude/sotto` (Expo Router client at `apps/client`, pnpm workspace). Read `planning/run7/PLAN.md` first, then your card, then the recon files it names. Recon claims marked VERIFIED are true until a file contradicts them; re-verify INFERRED before building on it.
- Vocabulary in code comments, commits, reports: "own-provider mode" (docs say BYOK), "the setting" (the value pasted in Settings), "the free origin" (readsotto.app), "the paid origin" (app.readsotto.app), "the plan". Product name: Sotto.
- Dev servers already run from the orchestrator: content server http://localhost:8790, Metro http://localhost:8081 (web). Do NOT start another Metro. If 8081 is down, write it in your report and stop. Playwright: copy the launch pattern from `apps/client/e2e/hosted.mjs`; put throwaway scripts and screenshots under `~/Claude/sotto-run7-recon/<lane>/`.
- Shared working tree with six parallel lanes. Edit ONLY the files your card lists as owned. Never `git add -A`, `git add .`, `git stash`, `git checkout`, `git reset`, `git clean`, `git rebase`, `git merge`. Never touch `packages/content/packs/**` (a regeneration job is writing there). Stage by explicit path, commit with prefix `run7(<lane>):`, then `git push origin HEAD`. Commit small and often.
- UI strings: every key must exist in all nine `apps/client/src/i18n/*.json`. Add or change them ONLY with `node apps/client/scripts/i18n-add.mjs '<json>'` (one atomic pass; provide real translations for ca, es, fr, it, pt, ro, zh-Hans, zh-Hant, not English fallbacks, before you finish).
- Tests: `pnpm --filter @sotto/client test` (vitest), `pnpm -r typecheck`, `pnpm lint`, `pnpm exec prettier --check <files>`. Bug fix = failing test first, then fix. `pnpm check` at the root currently fails on an untracked docs file; don't chase it, run the four pieces.
- Never print, log, screenshot or commit any secret, token, or the setting's value. Never read `.env` files. No real stored setting is available to you and you must not paste one.
- No deploys. No `vercel`, no `fly`.
- Done = proof in `planning/run7/<lane>-report.md`: what changed (files, SHAs), what you reproduced, screenshots list, tests run with output, what is NOT verified and why, anything needing Noel. Mark claims VERIFIED (you saw it) or INFERRED. Then stop. Two serious attempts at anything, then write the escalation in the report and stop.
