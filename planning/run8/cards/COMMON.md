# Common rules for every run 8 lane (read before your card)

- Repo `~/Claude/sotto` (Expo Router client at `apps/client`, pnpm workspace). Read `planning/run8/PLAN.md` (the fixed decisions), then your card, then `planning/run8/RECON.md`, then the mockup `planning/design/app-mockup-v2.html` and `planning/design/APP-V2-SPEC.md`. Recon claims marked VERIFIED are true until a file contradicts them.
- Vocabulary in code comments, commits, reports: "the free origin" (readsotto.app), "the paid origin" (app.readsotto.app), "the plan", "own-provider mode". Product name: Sotto.
- Dev servers already run from the orchestrator: content server http://localhost:8790, Metro http://localhost:8081 (web, real cloud/voice env). Do NOT start another Metro. If 8081 is down, write it in your report and stop. Screenshot helper: `cd ~/Claude/sotto/apps/client && node ~/Claude/sotto-run8/shots.mjs ~/Claude/sotto-run8/<lane>/` (seeds an onboarded en → fr-FR A2 profile with one in-progress book, shoots Home/Library/Reader at 375 and 1440). Baseline "before" shots: `~/Claude/sotto-run8/before/`. Put throwaway scripts and screenshots under `~/Claude/sotto-run8/<lane>/`, never in the repo.
- Shared working tree with parallel lanes. Edit ONLY the files your card lists as owned. Never `git add -A`, `git add .`, `git stash`, `git checkout`, `git reset`, `git clean`, `git rebase`, `git merge`. Never touch `packages/content/packs/**` (it has unrelated uncommitted changes; never stage them). Stage by explicit path, commit with prefix `run8(<lane>):`, then `git push origin HEAD`. Commit small and often; land the shared contract first.
- Every colour and size comes from `@sotto/core/theme` tokens (or `src/ui/tokens.ts` derivations). No inline hex in screens. The mockup's values that are not yet tokens are listed in PLAN.md decision 3; lane A adds them.
- UI strings: every key must exist in all nine `apps/client/src/i18n/*.json`. Add or change them ONLY with `node apps/client/scripts/i18n-add.mjs '<json>'` (one atomic pass; give real translations for ca, es, fr, it, pt, ro, zh-Hans, zh-Hant, never English fallbacks). Reuse existing keys where one already says the same thing.
- Tests: `pnpm --filter @sotto/client test` (vitest, pure logic only — `react-native` modules cannot be imported in tests, so put decisions in a `.ts` sibling like `railView.ts`), `pnpm -r typecheck`, `pnpm lint`, `pnpm exec prettier --check <files>`. Failing test first for every pure-logic change.
- e2e selectors: `apps/client/e2e/hosted.mjs`, `voice-live.mjs`, `audible-probe.mjs` drive the app by text and testIDs listed in RECON.md §8. Keep every one of them working (same testID, same visible text) or update the script in the same commit and say so.
- Never print, log, screenshot or commit any secret. Never read `.env` files. No deploys. No `vercel`, no `fly`.
- Done = proof in `planning/run8/<lane>-report.md`: what changed (files, SHAs), tests run with output, screenshot paths at 375 and 1440 next to the mockup frame they answer to, what is NOT verified and why, anything needing Noel. Mark claims VERIFIED (you saw it) or INFERRED. Two serious attempts at anything, then write the escalation in the report and stop.
